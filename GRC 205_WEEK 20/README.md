# GRC205 Week 20 - Incident Response Planning Assignment

## Overview
This repository contains the completed Week 20 assignment for Incident Management and Business Continuity, focused on developing a comprehensive Incident Response Plan for a ransomware attack scenario affecting a fictional educational institution, Northbridge Skills Institute.

## Assignment Objectives
The project demonstrates the ability to:
- Classify and assess cybersecurity incidents.
- Develop an Incident Response Plan (IRP).
- Define CSIRT roles and responsibilities.
- Create response playbooks and evidence preservation procedures.
- Design communication and escalation strategies.
- Conduct tabletop exercises and post-incident improvement planning.
- Analyze ransomware case studies and apply lessons learned.

## Scenario Summary
The assignment investigates a simulated ransomware incident involving:
- Compromised finance workstation (FIN-PC07)
- Impacted file server (FS01)
- Learning Management System (LMS01) disruption
- Suspicious privileged account activity
- Potential data exfiltration event
- Backup integrity concerns

The response prioritizes containment, evidence preservation, business continuity, secure recovery, and stakeholder communication.
